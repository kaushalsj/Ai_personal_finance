# AI Personal Finance and Smart Expense Predictor

## Project Overview
This project helps users manage their personal finances by tracking
income, expenses, and remaining balance. It provides charts,
budget alerts, expense summaries, and monthly expense predictions.

## Features
- Monthly income and expense tracking
- Remaining balance calculation
- Add new expenses
- Category-wise expense filtering
- Expense charts and visualizations
- Monthly expense trend
- Budget alerts
- Transaction search
- CSV data storage and download
- Monthly expense prediction

## Technologies Used
- Python
- Streamlit
- Pandas
- Matplotlib

## How to Run
1. Install Python.
2. Install dependencies:

   py -m pip install -r requirements.txt

3. Run the application:

   py -m streamlit run app.py

## Limitations
The current expense prediction is a demonstration and does not
use a trained Machine Learning model. The monthly trend chart
currently uses sample data.
